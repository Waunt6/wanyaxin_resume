# 小猫侦探 · 「我是谁」

万雅欣 Ayla 的个人主页。一只像素猫从左往右横向探索，六幕走完就把人讲完了。
纯静态，没有构建、没有依赖。

## 打开

双击 `index.html` 就能看。或者起个本地服务：

    python3 -m http.server 5178

## 一条连续的路

世界是一条不断开的路径，不是六个独立场景：

    房间地面 ──→ 绳子 ──↑── 绳顶平台 ──→ 台阶 ──→ 电视 ──→ 书 ──→ 城堡
                                                              ↓ 进门 loading
                                                            城堡内部 · 名片柱

| 幕 | 怎么走 |
|---|---|
| 01 房间 | 天花板垂下水晶吊灯、墙上两幅油画（点一下浮出小字）、地上一只百合花瓶 —— 全是真实素材。点画面任意一处 → 画面最左边垂下一根绳子，开场文字同时消失 |
| 02 绳子 | ↑ 箭头贴在**绳子**右侧（不是小猫头顶，它指的是那根绳子）→ 小猫**一路爬到房间完全出画**（第一个绳结在 -1820，爬约 1640）→ 点绳子上的青色圆圈 → 小猫爬到下一档停住，这一段教育就**浮在它旁边**（卡片顶对齐小猫头顶）。绳子本身不画绳结，圆圈就是绳结。爬到平台立刻松手（`cat.rope = false`），不然会一直保持攀爬姿势 |
| 03 台阶 | 绳顶就是一层平台，点 → 走上去 → 点圆圈一级一级上。小猫和圆圈都停在每一级的**外侧**（刚迈上来那个边沿），实习卡片左对齐在这一级的立面上，正好落在小猫右上方 |
| 04 电视 | 地上一台**坏掉的**银色电视，屏幕全是雪花。走到跟前小猫头上冒个气泡提示。点一下 → 电视放大、开机闪一下 → 屏幕里是一个 XP 桌面，四个像素文件夹＝四个项目。鼠标进屏幕变成像素箭头，点文件夹弹出蓝白 Win95 窗口讲这个项目。看完关掉，世界里那台电视就不再是雪花了，**这时候才**放出往下一幕的箭头 |
| 05 书 | 地上立着那本手账本（`assets/book.png`，棕色外壳的实拍图），走到跟前先冒个气泡，捡起来翻开就是**手账本的实拍页**。右侧五个标签＝五类爱好，鼠标悬浮亮一团柔光；**当前那一页不做任何标记**。合上之后小猫把本子收起来（`cat.hold = false`），再冒一个气泡，然后才放出往城堡的箭头 |
| 06 城堡 | 世界到尽头，镜头停住、**小猫自己走过去**；点门 → loading → 城堡内部 → 柱顶那只信封（`assets/envelope.png`）在光里，点开就是名片（`assets/namecard.png`，联系方式在图里），名片下面一行字。城堡 / 柱子 / 光 / 信封 / 名片都是真实素材 |

两条规则贯穿全程：

- **绳子有多长是算出来的**：要求「爬到第一个绳结时房间已经完全出画」。停住时可见区间是
  `[camY, camY+viewH]`，`camY = 猫y - ROPE_A*viewH`，所以 `猫y ≤ 房间最高处 - (1-ROPE_A)*viewH`。
  `viewH` 最大 1174（H≈783，`PX` 恰好还没跳到 3 那一档），房间最高处是吊灯顶含链条
  （`ROOM.lamp.y0 - CHAIN_LEN` = -735 - 88 = -823），
  反推出小猫要停在 -1527 以下 —— 取 -1638，最坏窗口还留 111 的余量。
  **抬吊灯就要同步缩链条**：房间顶是这两个数的差，差一变绳子的余量就跟着变。
  于是 `KNOT_Y[0] = -1820`。**`KNOT_Y[0]` 不能动**，它和 `KNOT_GAP` 一起钉住这个约束。
- **绳结间距 = 教育卡片的行距**：三张教育卡挂在三个绳结旁边，往下长，所以间距必须大于最高的那张。
  卡片带上「排名 / 课程 / 概述」之后，本科那张实测 344 高（430px 宽），间距取 380，留 36 的余量。
  间距一改，平台 `LV`、静态大图上边界 `PIX_Y0` 要跟着一起往上推：
  现在是 `KNOT_Y = [-1820, -2200, -2580]`、`LV = -2780`、`PIX_Y0 = -3810`。
  卡片挂在**小猫爬到的那一档**旁边（`EDU_TOP(i)` = `EDU_DEST(i) - CH - 10`，顶对齐小猫头顶）；
  最后一张例外 —— 它是站在平台上看的，平台有地面线，按头顶对齐会直接穿过地面，
  所以改成底边贴着地面往上排（`LV - 22 - offsetHeight`）。
  **给卡片加内容前先在控制台量一遍 `offsetHeight`**，超过 344 就要重新推这三个数；
  **改 `LV` 一定要同时检查 `PIX_Y0` 够不够高，否则城堡会被切顶。**
- **走路 500 / 爬绳 460**（`tick()` 里那两个 `s`），相机跟随 `dt*7`。
- **爬绳子是唯一一处小猫会在画面里升起来的**：镜头的竖向锚点从贴地的 `GROUND_A`(.86)
  平滑抬到 `ROPE_A`(.40)，所以小猫从画面底部一路升到三分之一处，地面顺势滑出画面。
  过渡距离是 `CLIMB_R × viewH`(.55)，这个比例必须大于 `GROUND_A - ROPE_A`(.46)，
  否则过渡期间地面会在画面里**往上弹一下**。往上爬时锚点直接取值（不做时间缓动，
  滞后会在停下的瞬间回摆约 20px）；爬到顶踩上平台、锚点跳回 .86 的那一下才做缓动。
- **空降 `jumpTo()`**：每一幕都把状态摆成「刚走到这儿」的样子（`cat.x/y`、`cat.rope/up`、
  `st.phase`、该亮的热点），再 `snapCam()` 让镜头瞬间吸过去 —— 不做位移动画，
  这个菜单存在的意义就是别再等了。
  **坑**：进城堡的 loading 和「点画浮字后掉绳子」都是 `setTimeout` 触发的，
  空降时必须 `clearTimeout` 掉，否则它们会在之后才执行，把刚摆好的状态又改回去。
- **换幕一定要点箭头**。箭头（`showGuide(dir,…)`）分四档，位置说明它指的是什么：
  `rope` 贴在**绳子**右侧 —— 它指那根绳子，不是小猫（这会儿小猫还站在离绳子挺远的地方）；
  `up` 浮在小猫头顶；`right` 贴在小猫右边（走两步）；
  `end` **钉在画面最右侧、写「继续向前」** —— 用在「这一段看完了，往下一幕」，
  它不属于世界里的任何位置，所以不跟着小猫走，坐标直接按视口算。
  到了新的一幕，上一幕的文字全部收掉，画面是干净的。
- **小猫头上的气泡**（`showBubble`）只在「该动手了」的地方出现：电视前、手账本前、合上手账本之后。
  它不用来讲内容 —— 内容都在世界里的卡片和覆盖层里。和箭头一样是视口层的 DOM，每帧跟着小猫走。
- **电视和手账本是「这一幕的正事」**：走到跟前只给气泡，**看完关掉才放出往下一幕的箭头**
  （在 `closeOverlay()` 里）。所以空降换幕必须走 `dismissOverlays()` 那个静默版，
  不然 `jumpTo` 会顺手把箭头也放出来，把刚摆好的状态搅乱。
- **姿势要跟着状态收**：爬到平台 `cat.rope = false`（否则一直是攀爬姿势），
  合上手账本 `cat.hold = false`（否则一直抱着本子）。
- **小猫钉在画面偏左，动的是环境**。只有最后城堡那一段因为世界到头了，镜头停住，小猫才真的走过屏幕。
  镜头没有「自由视角」这回事 —— 原来那个 `look` 开关连同拖拽/滚轮/方向键一起删掉了。

## 两套材质

- **世界**：全部是真·像素画，不是「画完再缩放」。所有线条用 `ph / pv / pl / pbox /
  pring / pdisc / parch` **逐像素点出来**（斜线走 Bresenham，圆走中点算法），
  1 缓冲像素 = 3 世界像素 = 小猫精灵的 1 格，所以世界和小猫共用同一套网格。
  静态部分在 `buildArt()` 里**一次性**画进一张世界大图 `pix`，每帧只按整数偏移
  裁一块 1:1 贴过来（不缩放、不插值），再最近邻放大 `PX` 倍上屏。
  相机也对齐到像素网格（`camXr / camYr`），所以画面不会有半像素抖动。
  地面是直线，台面下面加一排短横线当地砖缝 —— 马里奥那种做法。
  地面在画面里钉在 `GROUND_A`（.86）的高度，压得比较低，好让墙上的画和文字离顶栏远一点。
- **小猫**：像素。`js/cat.js` 用 mask 拼形状（圆角矩形 / 三角 / 圆），
  再取边界像素自动描边，所以头、身子、手臂各自是完整闭合的轮廓。
- **客厅的抠图**：花瓶和吊灯的原照片背景是灰墙、还带投影，普通漫水填充会直接穿过
  半透明的花瓶。用的办法是：逐行取左右两侧中位数估出墙色，然后**只保留比墙更亮
  或更有颜色的像素** —— 阴影比墙暗、又没颜色，就自然被当成背景剔掉了，
  正好对上「不要光影关系」。位置和尺寸都在 `js/app.js` 顶部的 `ROOM` 里。
- **房间的三样实物**：吊灯 / 两幅油画 / 百合，位置和尺寸全写在 `js/app.js` 顶部的 `ROOM` 里。
  每样只给一个边（宽或高），另一边按原图比例算出来 —— 换图不会变形。
  吊灯只取图里的灯体（`LAMP_SRC`），上面那截链条由 `drawChain()` 一环一环画出来，
  固定 `CHAIN_LEN`(88) 长 —— 不接天花板，灯就浮在世界里。
- **矮窗口的兜底 `fitTop()`**：地面上方能看到的世界高度是 `GROUND_A * viewH`，
  而 `viewH = H / SCALE`、`SCALE` 又按 `PX` 分档（2/3/4/5），所以常见窗口下它在 600~1000 之间跳。
  吊灯和开场文字都靠顶边，固定世界坐标会在矮窗口被顶出画面。
  `fitTop(y0, padPx)` 的规则是：正常窗口用设计好的 `y0`，只有离顶边不足 `padPx` 时才往下压。
  两者都在 `resize()` 里重算，拖窗口即时生效。
- **手账本**：`assets/journal-*.webp` 五张，正文、照片、贴纸全在图里，代码只负责换图。
  源文件是 `手账本/手账本透明背景PNG/`（已经抠好的），五张按同一个裁切框输出，
  所以换标签时书不会跳 —— 裁切框 1344×1127，`.book` 的 `aspect-ratio` 必须跟它一致，
  不然 `object-fit` 会留黑边，热区的百分比就对不上了。
  右侧五个索引贴是**图里画好的**，代码只在上面叠了五个透明热区（`.book .tabs button` 的
  `top/height` 百分比是从图里量的）。悬浮不画框，用的是一团 `radial-gradient` 柔光 ——
  方框压在纸上太硬。**当前页不做任何标记**：索引贴本身在图里就是有颜色的，
  再压一层青色柔光会脏。哪一页是当前页看内容就知道，书上方那行字负责告诉你索引贴能点。
- **城堡 / 柱子 / 打光**：`CASTLE` / `PILLAR` / `LIGHT` 三个配置，画在主画布上（`drawCastle()`）。
  门的热区不是写死的坐标，是 `CASTLE.door` 那组百分比乘出来的 —— 换城堡图只要重量一遍门的位置。
  柱子和光束的高度受「地面以上能看到多高」限制：那个值是 `GROUND_A * viewH`，
  最矮的一档窗口只有约 675，所以柱子 + 信封 + 光束加起来还留得下余量（`PILLAR.h` 260、`CARD_H` 68、`LIGHT.h` 420）。
  光束用普通 alpha 叠加，**不能用 screen** —— 底色是近白的，screen 会让这束光直接消失。
  出素材时做了三件事：底部那圈光晕是独立的一块（y 1300~1465，和锥体之间有一段全透明），整段裁掉；
  上面那截又细又实的锥尖也裁掉（从 y 210 起），因为那就是「看得见光源」的元凶；
  剩下的锥体再给顶部 42% 加一道指数渐隐，让光从虚无里慢慢出现。
  高度必须让这段渐隐在画面内走完（h ≤ 428，取 420）—— 再高顶端会被画面切掉，反而露出一条硬边。
  宽度**故意不按原图比例**（0.658 → 0.40），等于收小光锥的张角；照原比例画是一大团没形状的雾。
  城堡内部**没有背景线条**：原来那四道灰拱廊和天花板线在真实素材旁边显得很违和，全删了，
  只留地面。`parch()`（画半圆拱的）也跟着没人用了，一并删掉。
- **不做像素化的两样**：你给的**实物素材**（吊灯 / 油画 / 花瓶 / 手账本 / 电视 / 雪花 / 壁纸 / 文件夹 / 光标）
  和**交互热点**（青色圆环、四角标）—— 热点画在主画布最上层，平滑抗锯齿，
  这样它一眼就能和世界区分开。
- **机构标识（02 教育 / 03 实习）**：卡片顶上一行，左边 logo、右边身份小牌，底下一条细墨线。
  全站只有青色一个高音，品牌色是被允许的第二个，所以**默认是褪掉的墨色**
  （`grayscale(1) opacity(.5)`），等这张卡片亮起来（`.tx.on`）才慢慢回到品牌色 ——
  延迟 .3s、走 .6s，比正文慢半拍，最后才上色。
  `#layer` 是 `pointer-events:none`（点击一律交给 canvas），所以**不能用 hover 触发**，
  只能挂在 `.on` 上。
  **一样高不等于一样重**：四个 logo 笔画分量差很多，统一高度会让理想那种实心黑压死其它三个。
  按视觉分量各自定高（理想 17 / 快手 20 / 百度 22 / 华工 27），用 `[src$="…"]` 选择器写在 CSS 里。
  华工原图是「印章＋书法校名＋一行英文」，英文那行缩到 20px 高就是一团糊，
  出素材时按行投影切掉了（书法在 3–100 行，英文在 111–136 行），只留印章＋书法重新锁定。
  北科大和华工是同一种构图（印章＋书法校名＋一行英文），都按行投影切掉了英文那行。
  没有 logo 的可以用 `mark` 兜一个墨线字符牌（高度和 logo 一样），补了真图换成 `logo` 即可。
- **电视 / 桌面**：实物照片 + 90 年代 UI。
  世界里那台电视直接画在主画布上（跳过像素缓冲），而且画在小猫之前 —— 小猫从它前面走过。
  `assets/tv.png` 的屏幕开口是透明的，放大时内容层压在它下面，
  机身的银边天然把内容裁成 CRT 那个圆角形状。
  屏幕位置写在 `.tvscreen` / `.worldtv .wscreen` 的 `left/top/width/height` 里
  （9.03% / 34.30% / 63.36% / 47.11%），换电视图要重新量这四个数。

## 操作

- 点引导箭头 → 换到下一幕；点热点（青色圆圈 / 悬停时的四角标）→ 展开内容
- **画面不能拖、不能滚、方向键也不动**：镜头永远跟着小猫。想去别的地方只有顶栏那个章节菜单一条路。
  指针事件只剩「点」和「悬浮找热点」两件事，`#stage` 上了 `touch-action:none`，
  `html,body` 上了 `overscroll-behavior:none`（挡掉触控板横滑触发浏览器后退）
- **顶栏是可点的章节菜单**：点哪一幕就直接空降过去，不用一步步走。名字只出现在最后那张名片上
- Esc → 关掉覆盖层

## 调试

面板不可见时浏览器会暂停 rAF，控制台里用 `__d` 手推：

    __d.step(6)          推进 6 秒模拟
    __d.tap()            点当前那个引导箭头
    __d.run('kn0')       触发某个热点（kn0-2 绳结 / sp0-2 台阶 / tv0-3 / book / gate / card）
    __d.goTo(4000)       让小猫走到某个世界坐标

上线前可以从 `js/app.js` 末尾把 `__d` 删掉。
