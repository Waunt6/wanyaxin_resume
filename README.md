# 小猫侦探 · 「我是谁」

万雅欣 Ayla 的个人主页。一只像素猫从左往右横向探索，六幕走完就把人讲完了。

纯静态，没有构建、没有依赖，双击 `index.html` 即可打开。

---

## 六幕

| 幕 | 场景 | 内容 |
|---|---|---|
| 01 | 房间 | 水晶吊灯、油画、百合花瓶 —— 开场 |
| 02 | 绳子 | 沿绳攀爬，三张教育卡片浮在绳结旁 |
| 03 | 台阶 | 一级一级上，三段实习经历贴在台面 |
| 04 | 电视 | 坏掉的 CRT 开机后变成 XP 桌面，九个项目藏在像素文件夹里 |
| 05 | 手账本 | 捡起地上的本子，翻开五类爱好的实拍页 |
| 06 | 城堡 | 走到世界尽头，进门、点信封、展开名片 |

## 运行

```bash
# 直接打开
open index.html

# 或本地起服务（推荐，部分浏览器限制本地文件跨域）
python3 -m http.server 5178
```

## 文件结构

```
index.html          骨架 + 三个覆盖层（电视 / 手账本 / 名片）
css/style.css       全部样式
js/cat.js           像素猫（mask 造形 + 自动描边）
js/content.js       全部文案，改字只动这里
js/app.js           世界绘制 / 相机 / 交互
assets/             网站用到的所有图片素材
```

## 技术说明

- **世界**：全部像素画，逐像素点出来。静态部分一次性画进 `pix` 大图，每帧按整数偏移裁块贴上来，最近邻放大后不会有半像素抖动。
- **小猫**：`cat.js` 用 mask 拼形状，取边界像素自动描边，头 / 身子 / 手臂各自是完整闭合轮廓。
- **实物素材**：吊灯、油画、花瓶、手账本、电视、名片 —— 全是真实拍摄或绘制的图。

## 操作

- **点引导箭头** → 换到下一幕
- **点青色圆圈 / 悬停四角标** → 展开内容
- **顶栏章节菜单** → 直接空降到任意一幕
- `Esc` → 关掉当前覆盖层

## 调试

```js
// 控制台可用（上线前可从 js/app.js 末尾删掉 __d）
__d.step(6)          // 推进 6 秒模拟
__d.tap()            // 点当前引导箭头
__d.run('tv0')       // 触发热点（kn0-2 绳结 / sp0-2 台阶 / tv0-3 / book / gate / card）
__d.goTo(4000)       // 让小猫走到世界坐标 4000
```
